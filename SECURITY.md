# Security Policy

## Supported Versions

Security fixes are currently maintained for the latest `2.8.x` release.

| Version | Supported          |
| ------- | ------------------ |
| 2.8.x   | Yes                |
| < 2.8   | No                 |

## Reporting a Vulnerability

Please report security vulnerabilities privately through the GitHub security
advisory page:

https://github.com/HH2XX/EasyImages/security/advisories/new

Do not publish credentials, access tokens, private URLs, or a complete exploit
in a public issue. Include the affected version, deployment environment,
reproduction steps, impact, and any suggested mitigation. The HH2XX maintainer
will acknowledge valid reports and coordinate a fix and disclosure timeline.
